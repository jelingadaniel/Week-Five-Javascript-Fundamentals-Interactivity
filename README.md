# SpendWise Budget Tracker

## Project Description
SpendWise is a simple budgeting application that helps users track their budget and expenses.

## Features
- Enter a budget.
- Add multiple expenses.
- Calculate total expenses automatically.
- Display the remaining balance.
- Warn users when they exceed their budget.
- Update dashboard information dynamically.

## Technologies Used
- HTML – webpage structure.
- CSS – webpage styling.
- JavaScript – interactivity and calculations.

## JavaScript Concepts Implemented
1. Conditional statements (`if`, `else`).
2. Arrays for storing expense records.
3. Loops for processing expenses.
4. DOM manipulation for updating webpage content.
5. Event listeners for handling user interactions.

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
